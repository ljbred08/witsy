# Web Search Tool Selection Guidelines

## When to Use Normal Web Search vs Exa Search

### **Use Normal Web Search when:**
- Looking for general, introductory information
- Need quick answers to common questions
- Searching for popular or well-known topics
- Cost is a primary concern (free)
- Accepting of mixed-quality sources (blogs, forums, social media)

### **Use Exa Search when:**
- Need authoritative, technical content
- Require recent information (2024-2025)
- Searching specialized or niche topics
- Source credibility is important
- Need structured metadata (publication dates, authors, etc.)
- Budget allows for premium search ($0.01 per search)

### **Specific Recommendations:**

**For Programming/Technical Topics:**
- **Exa**: Python async best practices, current framework updates, performance optimization
- **Normal**: Basic programming concepts, common error solutions

### **Cost Consideration:**
- Exa charges $0.01 per search (transparently displayed)
- Normal web search is free
- Factor cost into tool selection for high-volume searches
